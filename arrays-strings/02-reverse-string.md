
## Problem: Reverse a String (Easy)

**Link:** https://leetcode.com/problems/reverse-string/

### Approach

We use two pointers, one at the beginning
and one at the end of the character array.
We swap the characters and move the pointers
towards the center.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

Learned how to reverse a character array
in-place using two pointers.
