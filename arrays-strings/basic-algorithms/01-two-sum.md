
## Problem: Two Sum (Easy)

**Link:** https://leetcode.com/problems/two-sum/

### Approach

We use two nested loops to check every pair
of elements in the array. If the sum of two
elements equals the target, we return their indices.

### Complexity

- Time: O(n²)
- Space: O(1)

### Notes

Tested using a typical case and a case
where the matching elements are not adjacent.
